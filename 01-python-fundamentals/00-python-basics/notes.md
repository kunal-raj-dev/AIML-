# Python Basics & Fundamentals Notes

## Key Concepts
- **Variables & Dynamic Typing**: Variables are created when assigned; types are resolved dynamically at runtime.
- **Data Types**: `int`, `float`, `str`, `bool`, `NoneType`.
- **Operators**:
  - Arithmetic: `+`, `-`, `*`, `/`, `//` (floor div), `%` (modulus), `**` (power)
  - Relational: `==`, `!=`, `<`, `>`, `<=`, `>=`
  - Assignment: `=`, `+=`, `-=`, `*=`, `/=`, etc.
  - Logical: `and`, `or`, `not`
- **Precedence**: Parentheses > `**` > `*`, `/`, `//`, `%` > `+`, `-` > Relational > `not` > `and` > `or`.
- **Type Conversion**: Implicit (automatic) vs Explicit casting (`int()`, `float()`, `str()`).
- **User Input**: `input()` always returns a string; use type casting for numerical computation.
