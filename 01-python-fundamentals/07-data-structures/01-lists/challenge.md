# Challenge: Remove Outliers & Find Median

## Requirements
- Write a function `clean_list(numbers)` that accepts a list of integers.
- Sort the list in ascending order.
- Remove the smallest and largest values (the outliers).
- Calculate and return the median value of the remaining numbers.

- ❌ No AI assistants
- ❌ No online tutorials

## Time Limit
