# Challenge: Inventory Stock Monitor

## Requirements
- Create a dictionary of items with their stock counts.
- Prompt the user to sell items. If sold, decrement stock.
- If stock drops to zero, notify user and remove the item from dictionary.
- Provide clear alerts if the item does not exist.

## Restrictions
- ❌ No AI assistants
- ❌ No online tutorials

## Time Limit
- ⏱️ 40 minutes
