# Challenge: Coordinate Distance Calculator

## Requirements
- Represent 2D coordinates as tuples: `point1 = (x1, y1)` and `point2 = (x2, y2)`.
- Write a function that calculates the Euclidean distance between these two points.
- Do not use external libraries except `math` (for square root).

## Restrictions
- ❌ No AI assistants
- ❌ No online tutorials

## Time Limit
- ⏱️ 30 minutes
