# Challenge: Vowel Substitution Cipher

## Requirements
- Take a sentence input from the user.
- Create a function `cipher(text)` that replaces all vowels (a, e, i, o, u) with their uppercase equivalents, and consonants with lowercase equivalents.
- Return the resulting formatted string.

## Restrictions
- ❌ No AI assistants
- ❌ No online tutorials

## Time Limit
- ⏱️ 30 minutes
