# Challenge: Gradebook Registry App

## Requirements
- Build a CLI Gradebook Application.
- Maintain a dictionary: keys are subject names, values are lists of student name/score tuples.
- Include options to: 1 - Add Grade, 2 - Calculate Class Averages per subject, 3 - Display Registry, 4 - Exit.

## Restrictions
- ❌ No AI assistants
- ❌ No online tutorials

## Time Limit
- ⏱️ 50 minutes
