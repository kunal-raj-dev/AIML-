# Challenge: ATM Console App Mockup

## Requirements
- Build a CLI ATM application.
- Keep track of account balances.
- Maintain a persistent loop prompting options: 1 - Check Balance, 2 - Deposit, 3 - Withdraw, 4 - Exit.
- Implement rules: check balance before withdrawals, handle non-integer inputs gracefully, and exit only when option 4 is selected.

## Restrictions
- ❌ No AI assistants
- ❌ No online tutorials

## Time Limit
- ⏱️ 45 minutes
