# Challenge: Student Grade Register Class

## Requirements
- Create a `Student` class.
- The constructor should initialize `name`, `roll_number`, and an empty list `grades`.
- Add an instance method `add_grade(grade)` to append a score to the grades list.
- Add an instance method `get_average()` returning the student average grade.
- Instantiate at least two student objects, record grades, and print averages.

## Restrictions
- ❌ No AI assistants
- ❌ No online tutorials

## Time Limit
- ⏱️ 45 minutes
