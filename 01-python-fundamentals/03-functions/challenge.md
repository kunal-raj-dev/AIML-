# Challenge: Grade Processing System

## Requirements
- Write a function `process_grades(*grades)` that accepts any number of student grades.
- Calculate the class average grade, maximum grade, and minimum grade.
- Return these three calculated values as a tuple.
- Handle edge cases where no grades are provided (should return zeros/empty parameters).

## Restrictions
- ❌ No AI assistants
- ❌ No online tutorials

## Time Limit
- ⏱️ 40 minutes
