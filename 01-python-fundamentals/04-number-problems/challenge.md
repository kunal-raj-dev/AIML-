# Challenge: Palindrome Integer Checker

## Requirements
- Accept an integer input from the user.
- Determine if the integer is a palindrome (reads same forward and backward) mathematically, without converting the number to a string.
- Use `%` and `//` operators in a loop to reverse the integer.
- Compare the reversed number with the original input and print results.

## Restrictions
- ❌ No AI assistants
- ❌ No online tutorials

## Time Limit
- ⏱️ 40 minutes
